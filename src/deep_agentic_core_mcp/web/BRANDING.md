# Consent page branding

`deepagentlabs.png` is the unmodified DeepAgentLabs logo from the official
website repository, `assets/img/dal-logo.png`. It is also bundled in the source
plugin's public listing assets.

`openai.svg` is the unmodified black Blossom SVG from OpenAI's official brand
archive, https://cdn.openai.com/brand/openai-logos.zip,
`OpenAI-logos/SVGs/OAI_OpenAI-Blossom_Black.svg`, retrieved 2026-11-26.
The OpenAI logo is owned by OpenAI and is used to identify ChatGPT on its
registered consent flow. See https://openai.com/brand/ for usage terms.
The mark is not used as DeepAgentLabs public plugin branding.

The consent page serves these packaged files locally; it does not load remote
brand assets. Only registered clients with a chatgpt.com callback display the
OpenAI mark. Other clients retain their initial badge.
