# MCP Server

How can an MCP client access supported DeepAgentLabs capabilities?

## What it does

Tool results, diagnostics, session context, and supported combined evidence workflows.

## What you need

MCP requests, supplied artifacts, configured producers, and server settings.

## Start here

Connect locally and inspect core.version, core.compatibility, and core.verify.

[Follow the quickstart](developer-guide.md#quickstart).

## Scope

Installed versions, adapter readiness, and runtime health are separate checks. Optional producer capabilities depend on the environment.

[Read the detailed developer guide](developer-guide.md).
